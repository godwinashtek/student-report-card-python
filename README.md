# Student Report Card

A simple Python project that demonstrates the use of variables and f-strings to generate a student's report card.

## Features
- Stores student information using variables
- Displays a formatted report card
- Uses Python f-strings for clean output

## Technologies Used
- Python 3

## How to Run
1. Clone this repository.
2. Open the project in your preferred Python IDE or editor.
3. Run the file:

```bash
python student_report_card.py
```

# Student Report Card

student_name = "Bre Tom"
age = 17
subject = "Mathematics"
score = 91.75

print(f"""==============================
STUDENT REPORT
==============================
Student : {student_name}
Age : {age} years
Subject : {subject}
Score : {score:.2f}%
Congratulations {student_name}!
You passed {subject}.
==============================""")
